## 1. 启动命令三模式

运行器详情的「启动命令」弹窗支持三档,切换即重新生成(`mode` 参数直通后端 `ExecutorLaunchCommandService`,与 MCP 工具 `ainative.build_executor_launch_command` 字节一致):

| mode | 命令形态 | 适用 |
|---|---|---|
| `foreground`(默认) | `npx -y ymai-codeflow@<v> connect …` | 调试、临时领单;关终端即停 |
| `nohup` | posix:`nohup … > "$HOME/ymai-codeflow-<id>.log" 2>&1 &`;windows:隐藏 PowerShell 窗口 | 挂机不装服务;崩溃不自动拉起 |
| `service` | `npx -y ymai-codeflow@<v> install-service connect …` | 长期运行节点(推荐) |

`service` 档由 CLI 的 `install-service` 落成平台守护进程:

- **macOS**:launchd LaunchAgent(`~/Library/LaunchAgents/com.ainative.executor.<id>.plist`,KeepAlive+RunAtLoad,日志 `~/Library/Logs/`)
- **Linux**:systemd user unit(`~/.config/systemd/user/ymai-codeflow-<id>.service`,Restart=always,日志 journald;自动尝试 enable-linger)
- **Windows**:登录时计划任务 + 自重启包装脚本(`%APPDATA%\AINative\`,等效 KeepAlive)

服务文件内嵌运行器令牌,CLI 落盘时自动 `chmod 600`;卸载统一 `ymai-codeflow uninstall-service --executor-id <id>`。预览不落盘:`install-service --dry-run [--os darwin|linux|windows]`。

> 复制启动命令的**两个入口都按当前选中的运行方式出命令**:运行器详情的「启动命令」弹窗,以及新建后的「运行器创建成功」弹窗。选「系统服务」复制到的就是 `install-service connect …`,可以直接贴到终端把运行器装成常驻服务(见 DEF-037)。

## 2. 编队一键配齐

模板建队后成员普遍缺运行器;逐个手建+配 token 的链路已收敛为一个入口:

- **入口**:编队详情 →「为成员配运行器」(仅管理员;前端 `SquadProvisionModal`)
- **后端**:`POST /squads/{squadId}/executors`(ADMIN)——`agentIds` 必须都是该编队成员(防越权挂靠);缺运行器的成员逐个创建+签发令牌+生成启动命令;已有运行器的成员返回 `SKIPPED_EXISTS`;**整批一个事务**,失败全回滚不留半初始化编队
- **产出**:逐成员状态(CREATED/SKIPPED_EXISTS/FAILED)+ 就绪命令 + 「复制全部」拼成一个 shell 脚本一次拉起全队
- 已知边界:一个运行器只能归属一个 AI 成员(创建时定死,无转移接口);要整队常驻就把每条命令换成 service 档执行

## 3. 运行器启动时间上报(0.3.32+)

runtime 心跳帧携带 `clientStartedAt`(进程级 UTC 时间,重连不重置),后端经 `updateLastStartedAt` 单调落库(仅新值覆盖旧值)。运行器列表「最近启动」列据此渲染;0.3.31 及以下客户端不上报,显示「未上报」——纯展示字段,不影响在线判定(那靠 `last_heartbeat`)。

## 4. 常用运维速查

```bash
# 前台试跑
ymai-codeflow connect --ws-url ws://<host>:7001/ws/executor --token exec_<id>_… --executor-id <id> --provider claude --memory-mode platform --max-tasks 5

# 常驻(装完即守护,崩溃自愈+开机自启)
ymai-codeflow install-service connect --ws-url … --token … --executor-id <id> …

# 抬高单步轮次上限(编码类大步骤默认 40 轮可能不够)
AINATIVE_AGENT_MAX_TURNS=120 ymai-codeflow connect …

# 卸载守护
ymai-codeflow uninstall-service --executor-id <id>
```

配套缺陷与经验见 07 号文档 DEF-036(runtime 隔离 HOME 吞登录态);npm 发版流程见 20 号文档。
